# Source refresh through the catalog archive

Follow-up to [the independent delivery pilot](./catalog-independent-delivery-pilot-2026-11-13.md). The collectors and analysis can now use a shared catalog store. The scheduled workflow still uses the legacy adapter. The November 18 refresh reached the 90 MiB staging guard without delivering the collected changes. Keep that guard in place until the scheduled path has passed a staging rehearsal with the new archive.

Run `node --import tsx scripts/refresh-catalog-store-pilot.ts` from the repository root with normal access to the public storefronts. The script copies the published data into `logs/catalog-pilot/source-refresh-*`, tries ALOHAS, Dear Frances and 24S, then builds a local delivery snapshot. Brand collection requires a matching storefront count, complete pagination and images. The 24S candidate uses the marketplace delivery gate. The script checks all previous model IDs, product and gallery URLs and the exact archive parts for untouched sources. The per-run `report.json` distinguishes what was collected from what was accepted. Shopify product URLs now use the storefront origin when the registry seed is a collection URL.

## Staging rehearsal

Run `node --import tsx scripts/rehearse-refresh-staging.ts`. The collected November 18 payload is not used: this run copies the archived rows and adds 3,966 synthetic rows to make a comparable 95,423,899-byte candidate. The legacy stage command rejects it at the unchanged 94,371,840-byte guard, leaving the index empty. The archive mode stages 139 files in a nested repository with no remote; the largest is 8,387,271 bytes. Only nine staged paths differ from the archive baseline. The run also rejects a file exactly at the threshold inside an allowed directory and restores both readable archives when analysis fails after writing the raw candidate. These measurements are local; the scheduled workflow has not switched over.

The Shopify collection report now separates the metadata count, deduplicated public rows and rows eligible for the catalog. ALOHAS `/collections/shoes`: 211 in collection metadata, 206 in the public list and 169 passing the women's-footwear filter on that path. The multi-collection collector found 178 eligible rows across all paths. Dear Frances: 77 was metadata for `/collections/flats`, whose public endpoint returned 46; it was not a brand total. No source is accepted by comparing a single category's number with the union of categories. Missing product payloads also fail the pagination check. The optional `--only=margaux --skip-marketplace` run uses Margaux's existing brand-specific count, gallery and membership checks.
